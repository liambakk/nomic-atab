# Working together

You can send the notes and files directly to Liam. There is no need to use Git to complete the handoff.

## If you want to edit the repository

With write access, open a file in GitHub and use its edit button. For a change that needs a second look, put it on a new branch and open a pull request for Liam.

The issue forms are available for general questions or updates. Keep client records and filled-in case notes in the private folder; the repository is public for now.

## Keeping the notes useful

- Say which workflow or case you are referring to.
- Point to the supporting file, or say who explained something and when.
- Flag gaps and anything based on memory.
- If an explanation changes, update the affected notes.

## Updating the Word guide

Liam or an engineer can update [brief.md](brief.md) and follow the [maintenance notes](docs/maintenance.md) to regenerate the Word copy. Keep the agreed Helvetica formatting: 11-point black text, with only the document title and main section headings bold.
