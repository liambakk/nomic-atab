# Completed handoffs

Use one folder for each selected company and workflow. Nothing has been selected or supplied in this repository at setup.

## Prepare a folder

For example, use this structure once the company and workflow are agreed:

```text
handoffs/<company-reference>/<workflow-reference>/
  company-profile.md
  workflow.md
  system-notes.md
  permissions.md
  case-001.md
  case-002.md
  case-003.md
```

Copy the files from [templates](../templates/company-profile.md), [system notes](../system-notes/README.md) and [permission record](../permissions.md). The three case files are the proposed starting request, not a requirement to invent cases when fewer exist.

Complete notes here only if their contents can be shared with the repository's collaborators. Otherwise use the same structure in the private handoff folder and record references here. Source exports stay in the private folder and are indexed in the root [manifest](../data-manifest.csv).

## Review a handoff

Use the [checklist](../handoff-checklist.md). Open a case-review issue when a case is ready, with its reference and any gaps. Liam reviews the material with the relevant business reviewer. Record corrections in the case and any reusable confirmed rules in system notes and the [decision log](../decisions.md).
